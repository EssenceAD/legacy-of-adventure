# EVAL_HINT_1021 — 평가단 점수 「어떻게 올려요?」 안내 (아자 건의)

> 건의: "식사 어울림, 평가단 점수 올리기에서 막혔는데요. 도대체 어떻게 해야 올리는 건지 절대 모르겠어요."

## 원인
- 평가 창(`ui/evaluation.ts` 평가 바)은 재료 이름 + `0/3` 숫자만 보여 준다. **무엇을 하면 오르는지**가 어디에도 없다.
- 특히 「식사 어울림」은 `themeHarmony.gourmet = [1, 6, 7, 18]` 중 완성한 어울림 수인데, 이 넷 중 **7(술통 창고)·18(향신료 텃밭)은 숨은 어울림**이라 도감에 힌트만 있다. 플레이어 입장에선 어떤 어울림을 만들어야 하는지 알 길이 없다.

## 수정

### A. 평가 창 — 재료마다 「어떻게 올려요?」 줄
각 `evrow` 아래에 작은 안내 줄(접힘 없이 항상 표시)을 붙인다. `evalParts()`의 `key`별 안내:

| 테마 | key | 안내 문구 |
|---|---|---|
| 미식 | meals | 단골이 주점에서 식사하면 1 (이번 시즌 시작 뒤부터 셈) |
| 미식 | harvests | 텃밭에서 수확하면 1 |
| 미식 | harmonies | 아래 「식사 어울림」 4개 중 완성한 수 (B 참고) |
| 미식 | mood | 손님 평균 기분 — 식사·온천·벤치·어울림으로 올라요 |
| 휴양 | mood | 손님 평균 기분 |
| 휴양 | harmonies | 「휴식 어울림」 8개 중 완성한 수 |
| 휴양 | decos | 마을에 놓은 장식 수 |
| 모험가 | wins / huntBest / trains / raids | 의뢰 성공 / 사냥 스테이지 합 / 훈련 횟수 / 토벌 도전 횟수 |
| 모험가 | harmonies | 「모험가 어울림」 6개 중 완성한 수 |
| 풍경 | decos / kinds / found / grade / roofs | 장식 수 / 장식 종류 수 / 발견한 어울림 수 / 마을 등급 / 지붕 색 가짓수 |

### B. 어울림 재료는 **목록으로 펼쳐 보여 준다** (핵심)
`harmonies` 줄 아래에 그 테마의 `themeHarmony` id를 전부 나열:
- **공개 어울림(open) 또는 이미 찾은 어울림**: `✅/⬜ 흥겨운 밤 — 주점 + 모닥불` (완성 여부 + 정확한 부품 이름)
- **숨은 어울림(아직 못 찾음)**: `⬜ 숨은 어울림 — 「술 냄새와 나무 냄새가 어울릴지도…」` (도감 힌트 그대로)
  - 단, 평가단 「아쉬움 힌트」로 힌트 단계가 올라간 어울림은 `harmony.ts`의 단계별 힌트(더 또렷한 것)를 쓴다.
- 각 줄을 누르면 **도감 → 어울림 해당 칸**으로 이동.
- 부품 이름은 `def(kind).name`으로, 대체 가능 부품(`K('a','b')`)은 `벤치(또는 장미 벤치)`처럼.

예(미식 시즌):
```
식사 어울림  1/3  ─ 아래 4개 중 3개를 완성하면 만점
  ✅ 흥겨운 밤 — 주점 + 모닥불
  ⬜ 장미 정원 — 텃밭 + 정자
  ⬜ 숨은 어울림 — 「술 냄새와 나무 냄새가 어울릴지도…」
  ⬜ 숨은 어울림 — 「갓 딴 채소가 바로 냄비로 들어간다면…」
```

### C. 시즌 시작 메일에 재료 요약 한 줄 추가
`평가 시즌 시작 · ○○ 부문` 메일 본문 끝에: `이번 시즌 점수 재료: 주점 식사 · 텃밭 수확 · 식사 어울림(흥겨운 밤·장미 정원 + 숨은 2개) · 식사 뒤 기분`.

### D. 설명서(manual.ts) 「평가단」 항목 보강
- 테마 4개마다 재료와 어울림 목록(숨은 건 "숨은 어울림 n개"로)을 적는다.
