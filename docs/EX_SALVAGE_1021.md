# EX_SALVAGE_1021 — 전용 무기가 일괄 분해에 갈림 (이카몰리 사고)

> "전용 무기가… 유물급도 아닌데… 일괄 분해에 갈리다뇨. 별 5개만 기다리고 있었는데."

## 원인 (코드 확인)
- 전용 무기는 `grade: 'a'`(유물)에 `item.ex`만 붙은 아이템이다 (`world/exWeapons.ts makeEx`).
- `world/craft.ts bulkTargets()`는 **끼운 것 · 🔒 잠금 · 강화·세트**만 빼고 `item.ex`를 보지 않는다. 유물 등급을 포함해 일괄 분해하면 전용 무기도 같이 갈린다.
- 「부위별 최고 1개 남기기」는 전투력 기준이라, 전용 무기가 아직 +0이고 다른 유물이 강하면 보호되지 않는다.
- 자동 분해(`world/items.ts`)도 같은 구멍이 있을 수 있다 — 확인.

## 수정

### A. 전용 무기는 어떤 분해에도 안 들어간다
- `bulkTargets()` · 자동 분해 · 가방 「한 번에 분해」 전부에서 `it.ex` 제외.
- 미리 보기 창에 `전용 무기 n자루는 빠져요` 한 줄.
- 한 개씩 분해(대장간 분해 탭·가방)에서 전용 무기를 고르면: **확인 창에 "전용" 경고 + 「분해」 글자를 직접 입력해야 진행**. 분해 시 **무기 조각 `frag.perBox`(10)개 반환**(=선택 상자 1개 값). 실수해도 되돌릴 길을 남긴다.
- 전용 무기는 받는 순간 `locked = true`로 준다(🔒). 플레이어가 풀 수는 있다.

### B. 이미 잃은 사람 자동 보상 (한 번만)
- 세이브 로드 시(마이그레이션 자리):
  ```
  for id in raidWeapon.got:
    granted = got[id]
    have   = bag.filter(x => x.ex === id).length   // 끼운 것 포함
    lost   = max(0, granted - have - (refunded[id] ?? 0))
    if lost > 0: frags += lost * perBox; refunded[id] = (refunded[id] ?? 0) + lost; 메일
  ```
- 세이브에 `raidWeapon.refunded: Record<string, number>` 추가(기본 `{}`).
- 메일(from: 'system'): 제목 「전용 무기 조각 환불」, 본문 「분해로 사라진 전용 무기 n자루의 조각을 돌려드려요. 이제 전용 무기는 일괄 분해에 들어가지 않아요.」, 보상 `frags`.
- 전수(`inh`)로 원래 무기가 바뀐 경우는 `got` 기준이 아니라 **가방에 ex가 하나라도 있으면 잃은 게 아님**으로 본다(위 식 그대로면 됨: have가 잡힌다).

### C. 패치 노트
- 🛡 전용 무기는 이제 **일괄 분해·자동 분해에 절대 안 들어가요**. 받으면 🔒 잠긴 채로 와요.
- 🔁 한 개씩 분해해도 **무기 조각 10개**를 돌려받아요.
- 💌 이미 분해로 잃은 분께는 접속 시 조각을 자동으로 돌려드렸어요(이카몰리 사고 보상).
