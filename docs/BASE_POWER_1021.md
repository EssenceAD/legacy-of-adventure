# BASE_POWER_1021 — 장비 뺀 「맨몸 전투력」 (아자 건의 10/20)

> "전투력 낮은 애들을 내보내고 싶은데 비교가 힘들어요. 장비를 다 빼고 비교해야 하는데 장비를 빼는 게 힘들어요. 한 번에 벗기 기능이나, 장비 빼고 순수 전투력·순수 스탯이 나오는 기능이 있으면 좋겠어요."

## 원인
- 카드·정렬이 전부 `powerOf(a)`(장비 포함)다. 누굴 내보낼지 고르려면 장비 영향 없는 **맨몸 전투력**이 필요한데 보여 주는 곳이 없다.
- `powerCalc(a)([])`로 장비 없는 값은 이미 계산 가능하다(핫픽스 12 §1). 화면만 붙이면 된다.

## 수정

### A. 「맨몸 전투력」 표시
- `basePower(a) = powerCalc(a)([])` 를 `world/adventurers.ts`에 export.
- **영웅 카드**(heroCard) 전투력 옆에 작은 회색 `맨몸 1,234` 를 붙인다(파티 덱·손님 목록 공통). 장비가 하나도 없으면 생략.
- **인물 정보 창**(personActions 정보 탭): 능력치 표에 `장비 포함 / 맨몸` 두 열. 맨몸 열 = `baseStats(a)` × 배수(영웅 ★·전설·인연·신화 — 장비 무관 배수만).

### B. 정렬에 「맨몸 전투력」 추가
- `SORTS = ['전투력', '맨몸 전투력', '레벨', '★']`. 정렬 키 `basePower(a)`.
- 손님 목록(guests)에서 내보내기 후보 고를 때 이 정렬이 기본으로 떠오르게: **「내보내기」 모드로 들어가면 정렬을 맨몸 전투력 오름차순으로 자동 전환**하고, 카드에 `맨몸` 값을 크게 보여 준다. 모드 나가면 원래 정렬로.

### C. 「장비 한 번에 벗기」
- 인물 정보 창 장비 탭에 `[장비 모두 벗기]` 버튼. 끼운 장비를 전부 가방으로(가방이 모자라면 들어가는 만큼만 + 토스트 "가방 n칸 모자라요").
- 작별 확인 시트(confirmSheet)에 **"끼운 장비 n개는 자동으로 가방에 돌아와요"** 한 줄 — 이미 그렇게 되어 있으면 문구만, 아니면 작별 시 자동 해제로.

### D. 도움말
- 설명서 「영웅」 항목: "맨몸 전투력 = 장비를 뺀 값. 내보낼 사람을 고를 땐 이걸로 비교해요."
