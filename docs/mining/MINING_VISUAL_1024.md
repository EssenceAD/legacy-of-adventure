# 「용사님, 채굴하실게요~」 — HD-2D 비주얼 가이드 (v1 · 2026-10-24)

## 1. 한 줄 (2026-10-24 확정)
**기준 그림 = pxl 공식 예제 `no_magic_night`** (마녀 오두막 밤 장면: 벽난로·촛불·가마솥 발광·장판 위 빛 웅덩이·먼지). 형철이 "이 느낌"으로 확정.
→ **낮은 해상도의 두툼한 픽셀 + 여러 개의 따뜻한 광원 + 발광 헤일로 + 어두운 앰비언트.** 체크인의 아기자기함을 유지하면서 "빛"이 화면을 만든다.
- 기준 해상도: 장면 **256×224 → 화면에 4~5배 정수 확대**(체크인과 같은 급). "2배 해상도"보다 **빛이 주인공**이다.
- 레퍼런스 파일: `claude-pxl/examples/no_magic.px.js` (1,005줄 · `lamp()` 6개 + `lighting({ambient:0.42})` + `glow()` 3종). Code는 이 파일을 먼저 읽고 같은 문법으로 만든다.

## 2. 기술
- **아트 제작: `claude-pxl` 스킬**(`crsolver/claude-pxl` · MIT · Node 22+) — 타일·소품·광석·이펙트·**장면 조명**을 `.px.js` 코드로 만든다. 한 팔레트로 전부 뽑아 색이 튀지 않고, Code가 한 칸씩 고치며 반복 가능(루프 엔지니어링과 궁합).
  - 빌드 산출물: 스프라이트 PNG + 시트 JSON + 노멀맵(`bump()`) + GIF. 게임은 이 PNG를 쓴다.
- **런타임: PixiJS v8 (WebGL)** — 체크인 캔버스 2D 렌더러는 쓰지 않는다. 시스템 코드와 렌더는 분리.
- 조명 2단계: ① 정적 장면(지상 마을·사무소 내부)은 **pxl이 구운 조명**을 그대로 쓴다(런타임 비용 0). ② 갱도처럼 광원이 움직이는 곳만 **런타임 라이트**(`@pixi/lights` + pxl `bump()` 노멀맵). 폰 성능은 ②에서만 신경 쓴다.
- 필터: 틸트 시프트(상하 블러) · 색온도 LUT(층별) · 비네팅. 전부 **저사양 모드에서 꺼짐**.
- 입자: 먼지 · 파편 · 불꽃 · 반딧불(발광 이끼) — 풀링, 폰 상한 300개.

## 3. 규칙
| 항목 | 규칙 |
|---|---|
| 해상도 | 장면 256×224 기준, 정수 확대. 캐릭터는 체크인과 같은 급(얼굴 GPT 재생성). 배경도 **픽셀**로(미드저니 고해상도 ✕ — 질감이 안 맞음) |

| UI | 체크인 UI 틀(나무·종이) 유지하되 **반투명 유리 + 빛 번짐 없는 테두리**로 한 단계 정돈 |
| 금지 | 블룸 과다 · 네온 · 3D 모델 · 실사 텍스처 |

## 7. Code 작업 지시 (비주얼 프로토타입)
1. `~/.claude/skills/pxl-pixel-art`에 `crsolver/claude-pxl` 클론. `examples/no_magic.px.js`를 끝까지 읽는다.
2. 같은 문법으로 `art/mine.px.js` 작성: 팔레트 하나(흙 갈색·바위 회보라·금 주황·발광 청록·랜턴 따뜻한 주황) → 갱도 타일 6종(노멀맵) · 광차 · 랜턴 · 광부 자리(임시) · 금광석/발광 광석 anim · 갱도 장면 1장(`lamp` 2개 + `lighting ambient 0.3` + `glow`).
3. 산출 PNG를 PixiJS에 올리고, 랜턴 하나만 런타임 라이트로 움직이게. 곡괭이 주스(§3). 웹 링크 → 형철 폰 확인.
