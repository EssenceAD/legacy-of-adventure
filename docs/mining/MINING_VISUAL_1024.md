# 「용사님, 채굴하실게요~」 — HD-2D 비주얼 가이드 (v1 · 2026-10-24)

## 1. 한 줄
**도트는 그대로, 빛과 움직임을 입힌다.** 옥토패스 트래블러 · 이스트워드 · 드래곤 퀘스트 3 HD-2D 계열. 체크인의 아기자기함은 유지하되, 갱도의 **어둠·랜턴·반짝임·먼지**로 한 단계 올린다.

## 2. 기술
- **PixiJS v8 (WebGL)** — 체크인 캔버스 2D 렌더러는 쓰지 않는다. 시스템 코드와 렌더는 분리.
- 조명: `@pixi/lights` 또는 자체 라이트 패스(랜턴 n개 + 발광 광석 + 용암). 스프라이트는 **자동 생성 노멀맵**(Laigter/SpriteIlluminator 배치 · 빌드 스크립트) 사용.
- 필터: 틸트 시프트(상하 블러) · 색온도 LUT(층별) · 비네팅. 전부 **저사양 모드에서 꺼짐**.
- 입자: 먼지 · 파편 · 불꽃 · 반딧불(발광 이끼) — 풀링, 폰 상한 300개.

## 3. 규칙
| 항목 | 규칙 |
|---|---|
| 해상도 | 캐릭터 도트 **체크인의 2배**(32→64px급)로 재생성. 지상 건물도 2배. 배경은 미드저니 고해상도 |
| 조명 | 갱도 기본 밝기 15%. 광원: 랜턴(따뜻한 주황, 반경 = 랜턴 등급), 광부 헤드램프(작은 노랑), 발광 광석(청록·보라, 맥동), 용암(붉은 깜빡임). 지상은 낮밤 + 창문 빛 |
| 층 색온도 | 뒷산 갈색/노을 · 폐광 청록/먼지 · 지하 호수 남색/물결 반사 · 드워프 도시 황금/보라 |
| 패럴랙스 | 갱도 3겹(먼 동굴 벽 0.2 · 중간 기둥 0.5 · 앞 종유석·먼지 1.3), 지상 4겹(하늘·먼 산·마을·앞 풀) |
| 틸트 시프트 | 화면 위아래 15%씩 블러 → 디오라마 느낌. 전투·시추 중엔 약하게 |
| 주스 | 곡괭이: 흔들림 2px + 히트 스톱 50ms + 파편 6개 / 광석 획득: 숫자 튀어오름 → 창고로 빨려 감 / 광차: 바퀴 불꽃·먼지 / 시세 상승: UI 펄스 / 큰 광맥: 슬로모 0.4s + 플래시 + 종 |
| 광석 | 광종별 셰이더 쉬머(철 무광 · 은 흰 반짝 · 금 따뜻한 반짝 · 보석 무지개 · 발광 광석 자체 발광+맥동) |
| UI | 체크인 UI 틀(나무·종이) 유지하되 **반투명 유리 + 빛 번짐 없는 테두리**로 한 단계 정돈 |
| 금지 | 블룸 과다 · 네온 · 3D 모델 · 실사 텍스처 |

## 4. 비주얼 프로토타입 (본 개발 전 통과 조건)
갱도 격자 1장(12×16) + 랜턴 1개 + 광부 1명 + 광차 1대 + 광맥 1개 + 곡괭이 주스 + 패럴랙스 3겹 + 틸트 시프트 + 저사양 토글. **형철 폰에서 "이 느낌 맞다" 확인 후** 본 개발.
